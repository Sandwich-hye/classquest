Introduction to Algebra (Year 8 Mathematics)
=============================================

Learning objective: understand variables, substitution, and solving
one-step linear equations.

1. A variable is a letter that stands for an unknown number, e.g. x.
2. Substitution: if x = 3, then 2x + 1 = 2(3) + 1 = 7.
3. Solving: to solve x + 5 = 12, subtract 5 from both sides -> x = 7.

Worked example:
   f(x) = 3x + 7, find f(4).
   f(4) = 3(4) + 7 = 12 + 7 = 19.
